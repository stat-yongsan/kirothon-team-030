# Requirements — 비교과 프로그램 결과보고서 검증 도우미

> 작성: Claude Code 사전 초안(2026-11-13). Kiro Quick Spec에서 생성된 문서가 아니다. 현장에서는 `challenge.md` 원문을 기준으로 kiro-cli가 change-topic 절차로 이 파일을 일괄 갱신한다.

## 범위

- 핵심 사용자: 대학 비교과 프로그램 운영 담당자 1명
- 핵심 흐름: CSV 입력 → 검증·집계 확인 → Claude 초안 → 검토 → Markdown 다운로드
- 기능 3개: ① 입력 검증·집계 ② Claude 초안 ③ 사용자 검토·내보내기
- 제외: 로그인, 결재 전송, 학사 시스템 연동, 개인별 학생 데이터, DB 저장

## Requirement 1 — 입력 검증·집계

**User Story:** 운영 담당자로서 CSV의 수치 오류를 행 단위로 확인하고 정확한 합계를 보고 싶다. 그래야 보고서에 틀린 숫자를 쓰지 않는다.

### Acceptance Criteria

1. WHEN 사용자가 정상 샘플(6행)을 불러오면 THEN 시스템은 신청자 140명, 수료자 115명, 집행액 2,800,000원, 전체 수료율 82.14%를 SHALL 표시한다.
2. 전체 수료율은 수료자 합계 ÷ 신청자 합계 × 100으로 SHALL 계산하며 프로그램별 수료율의 단순 평균(83.21%)을 쓰지 않는다.
3. WHEN CSV에 중복 행(프로그램명+부서), 신청자보다 많은 수료자, 누락 부서, 숫자가 아닌 집행액이 있으면 THEN 시스템은 각 오류를 원본 파일의 실제 행 번호(헤더 = 1행)와 함께 SHALL 표시한다.
4. WHEN 신청자가 0명인 행이 있으면 THEN 해당 수료율은 "계산 불가"로 SHALL 표시하고 Infinity·NaN·0%를 표시하지 않는다.
5. 따옴표 안 쉼표("글쓰기 클리닉, 심화")와 따옴표 안 천 단위 쉼표("900,000")를 SHALL 올바르게 읽는다.
6. WHEN 오류가 1건 이상이면 THEN AI 초안 요청을 SHALL 막고, 표시한 집계가 오류 행을 제외한 참고값임을 알린다.

## Requirement 2 — Claude 초안

**User Story:** 운영 담당자로서 검증된 수치로 결과보고서 초안을 받고 싶다. 그래야 작성 시간을 줄인다.

### Acceptance Criteria

1. 시스템은 코드가 계산한 근거 목록(ID·항목·값·출처)만 Claude에 SHALL 보내고, Claude 호출은 서버 Route Handler에서만 한다.
2. WHEN Claude 응답을 받으면 THEN 서버는 응답 스키마와 모든 근거 ID가 입력 근거에 존재하는지 SHALL 검증한다.
3. WHEN API 실패·시간 초과·잘린 출력·형식 오류·거절이 발생하면 THEN 화면은 "API 오류" 상태와 원인 코드를 SHALL 표시하고 샘플 응답으로 대체하지 않는다.
4. WHILE `AI_MODE=mock`이면 화면과 다운로드 파일에 "샘플 응답(mock)"을 SHALL 표시한다.
5. 입력 데이터 안의 지시문은 데이터로만 SHALL 다루고 시스템 지침을 바꾸지 않는다.

## Requirement 3 — 사용자 검토·내보내기

**User Story:** 운영 담당자로서 초안을 고치고 검토 완료를 표시한 뒤 파일로 받고 싶다. 그래야 결재 문서에 옮길 수 있다.

### Acceptance Criteria

1. 사용자는 요약·섹션 제목·본문을 SHALL 편집할 수 있고, 각 섹션 아래 연결된 근거(ID·값·출처)를 본다.
2. WHEN 검토 확인란을 체크하면 THEN 상태가 "검토 완료"로 SHALL 바뀌고 Markdown 다운로드가 활성화된다. WHEN 검토 후 내용을 고치면 THEN 다시 "미검토"가 된다.
3. 다운로드 파일은 AI 모드, 검토 상태, 편집된 본문, 섹션별 근거, 코드 집계 표, 근거 목록을 SHALL 포함한다.
4. 화면은 초기·샘플 선택·입력 오류·분석 중·결과·API 오류·검토 완료 상태를 텍스트로 SHALL 구분한다.
5. 1440px 데스크톱과 390px 모바일에서 가로 넘침 없이 주 동작 버튼이 SHALL 보인다.
