# UI 규칙

- 한 페이지: ① 생각 담기 ② 밤 작업 보드(잠자리채에 맡기기) ③ 아침 브리핑 ④ 연결 상태. 주 동작 버튼은 단계마다 하나.
- 상태를 문구로 구분한다: 저장됨·대기·예약됨·정리 중(현재 단계)·완료·부분 완료·내 답변 필요·외부 조치 필요·실패·취소됨. 색만으로 구분하지 않고 근거 없는 진행률(%)을 쓰지 않는다.
- 샘플 결과는 "샘플" 배지, 실제 결과는 "kiro-cli 실제 생성" 배지. 워커가 꺼져 있으면 "워커 꺼짐"을 표시한다.
- 시각 방향: 네오 브루탈리즘(굵은 검은 테두리, 하드 그림자, 노랑·분홍·보라·초록, 폴더 탭 카드).
- 접근성: 모든 입력에 label, 상태 영역 `role="status"`, 오류 `role="alert"`, 키보드 focus 표시.
- 1440px·390px에서 페이지 가로 넘침 금지. 넓은 표는 자체 `overflow-x-auto` 컨테이너에 둔다.
