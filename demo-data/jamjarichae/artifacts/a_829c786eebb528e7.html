확산 모델(Diffusion Model)

W2 개념알기 · 영상(MP4)상태: 완료 입력 날짜 2026-11-14생성 엔진: kiro-cli headless

아침 브리핑

  • 확산 모델은 노이즈를 더하는 과정을 거꾸로 학습해 데이터를 생성하며, 뿌리는 2015년 비평형 열역학 기반 제안이다.
  • 2020년 DDPM이 고품질 이미지 합성을 보여 주었다.
  • 최근 연구는 적은 단계로 생성하는 증류와 flow matching 기반 모델의 확장에 쏠려 있다.

다음 행동 DDPM 원 논문(arXiv 2006.11239)의 학습·샘플링 알고리즘 부분을 읽고 위 실험을 실행해 본다.

한 문장 정의

데이터에 노이즈를 단계적으로 더하는 과정을 역으로 학습해, 순수 노이즈에서 이미지 같은 데이터를 만들어 내는 생성 모델이다.

쉬운 예시 사진에 지지직 노이즈를 조금씩 얹어 완전한 잡음으로 만든 뒤, 그 과정을 거꾸로 되돌리는 법을 신경망에게 가르친다. 학습이 끝나면 무작위 잡음에서 시작해 노이즈를 한 단계씩 걷어내며 새 그림을 얻는다.

해석 가정: 머신러닝의 생성 모델인 확산 모델(DDPM 계열). 메모에 영문 'Diffusion Model'이 병기되어 있어 이 해석을 골랐다.

어떻게 작동하나

  • 정방향 과정: 원본 데이터에 여러 단계에 걸쳐 가우시안 노이즈를 더해 마지막에는 거의 순수한 노이즈로 만든다.
  • 학습: 신경망이 각 단계에서 섞인 노이즈를 예측하도록 훈련한다(DDPM에서는 노이즈 예측 손실을 쓴다).
  • 역방향 생성: 무작위 노이즈에서 시작해 학습된 신경망으로 노이즈를 한 단계씩 제거하며 샘플을 만든다.
  • 조건부 생성: 텍스트 같은 조건을 신경망에 넣어, 프롬프트에 맞는 결과가 나오도록 유도한다.
  • 속도 개선: 샘플링 단계 수를 줄이는 증류(distillation) 등으로 적은 단계에서도 생성하도록 가속한다.
  • 최근에는 확산 모델과 flow matching(rectified flow) 방식이 함께 쓰이며, 대표 모델도 두 방식이 섞여 있다.

필요한 용어

  • 정방향(forward) 과정 — 데이터에 노이즈를 단계적으로 더하는 과정
  • 역방향(reverse) 과정 — 노이즈를 제거하며 데이터를 복원하는, 학습 대상이 되는 과정
  • DDPM — Ho 등(2020)이 제시한, 고품질 이미지 합성을 보인 확산 확률 모델
  • 노이즈 스케줄 — 각 단계에서 노이즈를 얼마나 더할지 정하는 규칙
  • 샘플링 단계 수 — 생성 시 노이즈를 걷어내는 반복 횟수. 많을수록 대체로 느리다.
  • 증류(distillation) — 많은 단계가 필요한 모델을 적은 단계로 생성하는 학생 모델로 압축하는 기법
  • flow matching / rectified flow — 노이즈에서 데이터로 가는 경로(흐름)를 직접 학습하는 관련 방식
  • FID — 생성 이미지 품질을 실제 이미지 분포와 비교해 재는 대표 지표. 낮을수록 좋다.

언제·왜 등장했나

  • 2015 Sohl-Dickstein 등이 비평형 열역학에서 착안해, 데이터 구조를 서서히 파괴하는 정방향 확산과 이를 복원하는 역방향 과정으로 생성 모델을 만드는 방법을 제안했다. [S1]
  • 2020 Ho, Jain, Abbeel이 DDPM으로 확산 확률 모델의 고품질 이미지 합성 결과를 보고했다. [S2]

지금 가능한 것 / 아직 어려운 것

가능어려움
  • 이미지 생성(텍스트 → 이미지)
  • 이미지·영상 합성 및 편집
  • 오디오·음성 등 다른 모달리티 생성(서베이에서 언급)
  • 단백질·소재 합성, 날씨 예측, 편미분방정식 대리 모델 등 과학 분야 응용(arXiv 2402.04384 도입부에서 언급)
  • 적대적 공격에 대한 입력 정화(DDPM 기반 방어 연구 사례)
  • 사전학습된 모델에 LoRA 어댑터를 붙여 새 능력(예: 이미지→텍스트)을 추가하는 시도(FullFlow)
  • 샘플링에 여러 번의 신경망 계산이 필요해 느리다. 이를 줄이는 증류가 활발히 연구된다.
  • 클래스 조건 생성에서 잘 되던 증류가 자유 형식 텍스트 프롬프트로는 효과가 불분명해, 별도 연구가 필요하다.
  • 텍스트처럼 이산적인 데이터는 연속 이미지 확산을 그대로 쓰기 어렵다(FullFlow는 별도의 이산 삽입 과정을 추가).
  • DDPM의 이론적 수렴 분석이 아직 연구 중이다.

Few-Step Distillation for Text-to-Image Generation: A Practical Guide 프리프린트
확인하지 못함(제출자: Yifan Pu) · 2025-12 · arXiv (cs.CV) · 근거 S3

기여 텍스트-이미지 교사 모델 FLUX.1-lite에 최신 증류 기법들을 통일된 틀로 적용·비교하고, 입력 스케일링·구조·하이퍼파라미터 지침과 오픈소스 구현 및 학생 모델을 제공했다.

한계 프리프린트이며 FLUX.1-lite 한 교사 모델 중심의 비교다. 이 보고서에서는 초록만 확인했고 본문 수치는 읽지 않았다.

FullFlow: Upgrading Text-to-Image Flow Matching Models for Bidirectional Vision–Language Generation 프리프린트
확인하지 못함(제출자: Eric Tillmann Bill) · 2026-05 · arXiv (cs.CV, cs.AI) · 근거 S4

기여 사전학습된 rectified-flow 텍스트-이미지 모델에 LoRA 어댑터와 가벼운 텍스트 헤드만 학습해 양방향(텍스트↔이미지) 생성기로 바꾸는 방법. 저자들은 SD3에서 text→image FID를 62.7에서 31.6으로 낮췄다고 보고했다.

한계 프리프린트이며 수치는 저자 보고값이다. 비교 대상은 LoRA로 맞춘 Dual Diffusion 방식이며, 독립 재현은 확인하지 못했다.
