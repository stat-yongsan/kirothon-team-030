# 연습 문제 2 — 행사 절차 안내 도우미 (연습용 가상 규정)

> 아래 규정은 **연습용 가상 규정**이다. 실제 대학 규정이 아니다.

## 문제 설명(가상)

부서 담당자가 비교과 행사를 열 때 신청 기한, 예산에 따른 검토자, 결과보고 마감을 규정에서 매번 찾아야 한다. 행사 계획 CSV를 넣으면 규정에 대조해 행사별 절차를 알려 주고, 근거 규정 ID를 연결한 안내문 초안을 만드는 도구가 필요하다.

## 연습용 가상 규정

| ID | 내용 | 출처 이름 |
|---|---|---|
| RULE-APPLY-7D | 행사 시작 7일 전까지 신청 | 연습용 가상 규정 제3조 |
| RULE-REVIEW-DEPT | 예산 50만원 이하: 부서장 검토 | 연습용 가상 규정 제4조 제1항 |
| RULE-REVIEW-CENTER | 예산 50만원 초과: 센터장 검토 | 연습용 가상 규정 제4조 제2항 |
| RULE-REPORT-14D | 행사 종료 후 14일 이내 결과보고 | 연습용 가상 규정 제5조 |

## 예상 결과(검산 기준)

| 입력 | 기대 결과 |
|---|---|
| 정상 3건 | 겨울 코딩 캠프: 마감 12-03 충족·부서장·보고 12-24 / 진로 박람회: 마감 12-08 충족·센터장·보고 12-30 / 신년 독서 모임: 마감 2027-01-01·보고 2027-01-22 |
| 오류 | 2행 2026-02-30 없는 날짜 / 3행 종료 < 시작 / 4행 예산 "미정" → 오류 3건 |
| 경계값 | 정확히 7일 전 신청 = 충족, 6일 전 = 미충족(주의) / 500,000원 = 부서장, 500,001원 = 센터장 |

전환 방법: `src/domain/current.ts`에서 `programReport` 대신 `regulationGuide`를 연결하고 change-topic 절차로 Spec·문구·대본을 맞춘다. 2026-11-13 복사본에서 시험한 결과는 `docs/SETUP_STATUS.md` 참고.
