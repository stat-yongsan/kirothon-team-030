# 연습 문제 1 — 비교과 프로그램 결과보고서 검증 도우미 (기본 작동 예제)

## 문제 설명(가상)

대학 비교과 프로그램 운영 담당자는 학기 말에 프로그램별 신청자수·수료자수·집행액을 CSV로 모아 결과보고서를 쓴다. 수치 오류(중복, 수료자 > 신청자, 누락, 숫자 아닌 값)를 찾는 데 시간이 들고, 수료율을 잘못 계산하기 쉽다. 오류를 바로잡고 근거가 연결된 보고서 초안을 빠르게 만드는 도구가 필요하다.

## 예상 결과(검산 기준)

| 입력 | 기대 결과 |
|---|---|
| 정상 샘플 6행 | 신청 140명, 수료 115명, 집행 2,800,000원, 전체 수료율 115/140×100 = **82.14%** (단순 평균 83.21% 아님) |
| 오류 샘플 | 3행 수료 31 > 신청 25 / 4행 부서 누락 / 5행 집행액 "오십만원" / 6행 2행과 중복 → 오류 4건, 초안 불가 |
| 경계값 샘플 | 신청 0명 행 수료율 "계산 불가", 전체 27/30 = 90.00% |
| 초안 | 섹션마다 근거 ID(SUM-*, ROW-<행번호>), 검토 후 `program-report.md` 다운로드 |

데이터: `src/domain/fixtures/program-report.ts` (손 검산 주석 포함)
