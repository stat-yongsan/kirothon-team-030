## 시연 전 준비 (5분 전)

1. `npm.cmd run dev` → http://localhost:3000
2. 별도 터미널에서 `npm.cmd run worker` → "연결 상태"에 `야간 워커: 연결됨`, `생성 엔진 kiro-cli: 연결됨`이 보이는지 확인
3. 밤 작업 보드에 오늘 만든 실제 결과 카드가 있는지 확인(벡터 데이터베이스, 아이디어 5개, 체험 페이지, 잠자리 - 위키백과, Me at the zoo, 북토크)
